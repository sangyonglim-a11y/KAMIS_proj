# 도매 시세 예측 대시보드

프로젝트 경로: `/home/ubuntu/kamis-dashboard`. 브랜치 `cursor/kamis-wholesale-dashboard-4f06`, 최신 커밋 `e574d6a`. 앞선 실시간 조회 기록은 `internal/kamis-dashboard.md`. 원격이 없어 push와 PR은 하지 않았다. 구글 시트와 웹 앱은 연결됐다. 키와 웹 앱 주소는 `.env.local`에만 있다.

## 실행

```bash
cd ~/kamis-dashboard
npm install
cp .env.example .env.local
npm run dev
```

`.env.local`에 `SHEET_CSV_URL`, `GAS_WEBAPP_URL`, 필요하면 `GAS_APP_TOKEN`을 넣고 서버를 다시 시작한다. 주소가 없으면 차트를 그리지 않고 연결 안내만 보여 준다.

## 시트

`setup()`이 만드는 시트.

- `품목`: 품목코드, 품목명, 부류코드, KAMIS품목코드, 품종코드, 품종명, 단위, 등급코드, 등록일. 품목코드는 `sangchu` 같은 프리셋 id.
- `시세`: 날짜, 품목코드, 품목명, 구분(`일별`|`월간`), 도매가, 단위, 거래동향, `AI_예측`, 매입액션, 수집시각. 월간 행의 날짜는 `YYYY-MM-01`. 같은 날짜·품목·구분은 다시 넣지 않는다.

CSV는 서버만 읽는다. `https://docs.google.com/spreadsheets/d/시트ID/gviz/tq?tqx=out:csv&sheet=시세` 형태이고, 시트를 링크가 있는 사용자에게 보기로 연다. 로그인 HTML이 오면 502.

## Apps Script

파일: `apps-script/Code.gs`. 웹 앱은 실행 계정 본인, 액세스 모든 사용자. 프로젝트 시간대는 `Asia/Seoul`. 스크립트 속성: `KAMIS_CERT_KEY`, `KAMIS_CERT_ID`, `GEMINI_API_KEY`, 선택 `GEMINI_MODEL`(기본 `gemini-2.5-flash`), 선택 `APP_TOKEN`.

- `doPost`: JSON의 `itemCode`/`itemName`과 Next가 같이 보내는 부류·품목·품종 코드로 품목을 정한다. 확인된 10개만 받는다. 어제까지 24개월을 180일 단위로 `periodProductList`(도매 `02`, 등급 `04`, 원래 단위, 전국 평균)로 가져 시트 아래에 붙인다. 응답 날짜가 요청 구간 밖이면 버린다.
- `monthlySalesList` (`p_yyyy` 올해, `p_period=3`, `p_graderank=1`)의 월평균을 `구분=월간`으로 넣는다. 전년·전전년 같은 달 패턴은 이 값이다.
- 거래동향은 `https://www.kamis.or.kr/customer/trend/trade/daily.do?action=list`에서 소매·중도매를 구분 없이(`productclscode` 비움, `period=7`) 읽고, 품종 제목이 맞는 글을 날짜별로 모은다. 품목 추가와 일일 수집은 오늘 기준 약 4주(7일 간격 4페이지)를 Gemini 프롬프트에 넣고, 각 날짜 칸에도 적는다.
- `installDailyTrigger()`는 기존 `collectDaily` 트리거를 지우고 매일 7시에 다시 건다. 등록 품목의 최근 7일 일별, 전일 동향, 예측을 갱신한다.
- Gemini 프롬프트는 최근 30거래일, 그 구간의 변동률, 올해·전년·전전년 같은 달 월평균, 당일 동향을 넣고, 10~20일 흐름과 지금 살지 2주 미룰지를 3문장 이내로 쓰라고 지시한다. 응답 JSON의 `summary`는 `AI_예측`, `action`은 `매입액션`(적극 매입, 관망, 소량 분할 매입, 매입 보류)으로 최신 일별 행에만 적는다. 키가 없으면 시세는 저장하고 경고만 돌려준다.

AI 카드 테두리는 적극 매입 녹색, 소량 분할 매입 황색, 관망 회색, 매입 보류 파랑.

기존 `/api/kamis` 실시간 프록시는 그대로다. 기본 화면은 시트다. 시트 차트는 상품 한 계열이다. 중품·전년 점선은 예전 실시간 화면 로직에 남아 있다.

10개 프리셋의 부류·품목·품종·등급 04/05는 코드표에 그대로 있다. 품목명만 화면과 다른 것이 셋이다. 246은 파(품종 00 대파), 242는 풋고추(품종 03 청양고추), 258은 깐마늘(국산)(품종 03 깐마늘(대서)). `파`, `깐마늘(대서)`, `수미(노지)`는 추가 입력으로 받는다. 무는 품종 조건을 비워 상품 20kg 전체를 날짜별로 평균한다. `가을`은 배추 품종이고, `전체`는 무의 화면 이름이라 품종명만으로는 받지 않는다. `풋고추`와 `깐마늘(국산)`은 품종이 여러 개라 받지 않는다.

## 구글 시트 연결

시트 제목은 `KAMIS 도매 시세`이다. 주소는 `https://docs.google.com/spreadsheets/d/1hKZvI3-q0tGP84-za1UTrswVRVdsTaR_Y1HkIiAuzZs/edit`. 일반 액세스는 링크가 있는 모든 사용자, 역할은 뷰어다. `시세` CSV를 로그인 없이 읽으면 헤더와 상추 일별이 나온다.

웹 앱은 2026-10-29 버전 1로 배포됐다. 실행은 사용자 본인, 액세스는 모든 사용자, 매니페스트 시간대는 `Asia/Seoul`이다. `doGet`은 `{"ok":true,"service":"kamis-forecast"}`를 돌려준다. 스크립트 속성에는 공공데이터 키, Gemini 키, `APP_TOKEN`이 있다. 값은 적지 않는다. `.env.local`의 `GAS_WEBAPP_URL`, `GAS_APP_TOKEN`, `SHEET_CSV_URL`도 커밋하지 않았다.

`installDailyTrigger` 실행 로그는 시작 후 완료로 끝났고, 트리거 목록에 `collectDaily`, 이벤트 `시간 기반`, 배포 `Head`가 하나 있다. 시각은 코드의 7시다. 트리거는 편집기에 저장된 최신 스크립트를 실행한다. 배포 버전 1에는 `padCode_`가 없다. 저장소 커밋 `b526fa7`에는 있다. `품목`의 상추 품종코드와 등급코드는 텍스트 `02`, `04`로 다시 넣었다.

상추 수집은 웹 앱이 처리했다. `시세`는 2024-10-28부터 2026-10-28까지 일별 487일이고 같은 날짜 중복은 없다. 2024-10-28은 45,600원, 2026-10-28은 17,800원이다. 수집시각은 2026-10-29 19:08 (서울)이다. 2026-10-28 거래동향에는 소매 대전, 100g 상품 700원이 있다. 그 행의 매입액션은 `소량 분할 매입`이고, 문장은 12,000원대 최저점에서 17,000원 후반대로 반등한 뒤 공급 축소 강보합이 예상되므로, 저장성이 짧은 상추는 2주를 통째로 미루기보다 필요한 물량을 나누어 사라는 세 문장이다. 이전 로컬 수집의 `적극 매입` 문장은 이 시트 수집이 덮어썼다.

`GET /api/sheet?itemCode=sangchu&period=1m`은 200이고 같은 날짜, 가격, 동향, 액션을 준다. 브라우저 `http://localhost:3000`에서 상추 칩, 최근 1개월 차트, 2026년 10월 28일 카드, 대전 700원, 황색 `소량 분할 매입` 카드를 확인했다. `127.0.0.1`로 열면 개발 서버가 클라이언트 리소스를 막아 차트가 비어 있다.

## 무 품종 전체

KAMIS 간편가격정보의 무 전체 20kg과 맞추려고 무만 품종 필터를 뺐다. 배추는 가을 03이다. 품종 코드가 비면 `cond[vrty_cd::EQ]`를 보내지 않는다. `00`은 전체가 아니라 대파·양파의 품종 코드라 쓰지 않았다. 같은 날 여러 품종이 있으면 조사 시장 가격을 한 번에 단순 평균한다. 품종별로 먼저 평균한 뒤 다시 평균하지 않는다.

편집기 Head의 `refreshMu`가 기존 가을 무 일별을 지우고 다시 넣었다. `시세`의 무는 2024-10-28부터 2026-10-28까지 487일이고 14일보다 긴 공백은 없다. `품목` 행은 품종코드가 비어 있고 품종명은 `전체`다. 커밋 `ecf2b89`.

확인한 상품 20kg 평균: 2026-09-28 20,280원, 2026-10-13 19,920원, 2026-10-28 13,011원. 앞의 두 날은 고랭지뿐이라 KAMIS 전체 화면과 같다. 2026-06-02는 봄·월동이 섞여 15,550원이다. 2026-10-26은 14,557원, 2026-10-27은 13,575원이다. 최근 1개월 `GET /api/sheet?itemCode=mu&period=1m`은 거래일 21일, 구간 2026-09-28~2026-10-28이다. 2026-10-28 전일 대비는 −564원(−4.2%)이다.

2026-10-28 매입액션은 `매입 보류`다. 문장은 가을무 출하와 품종 다양화로 공급이 늘어 13,000원 선까지 내렸고, 김장 성수기 전까지 약보합이 이어질 수 있어 대량 구매를 피하고 2주 뒤로 미루라는 세 문장이다. 그 행의 거래동향 칸은 비어 있다. 카드는 “이 날짜에 저장된 KAMIS 거래동향이 없습니다”라고 보여 준다. 가격을 다시 지우고 받지 않았다.

배포 버전 1은 아직 가을 무이고 기존 행을 지우지 않는다. 매일 7시 트리거는 Head라 다음 수집부터 품종 전체를 쓴다. 화면의 `+ 신규 품목 추가`는 버전 1을 호출하므로, 그 버튼으로 무를 다시 넣기 전에 웹 앱을 다시 배포해야 한다.

`http://localhost:3000`에서 무 칩, 최근 2년(실제 거래일 487일), 최근 1개월(2026.09.28–2026.10.28, 13,011원, 매입 보류)을 확인했다.

## 품목 다섯 개 추가

코드표 기준이다. 양배추는 부류 200, 품목 212, 품종 00, 8kg. 청오이는 오이 223의 품종 03 취청, 50개. 팽이버섯은 부류 300, 품목 316, 품종 00, 5kg. 주키니호박은 호박 224의 품종 02 쥬키니, 10kg. 애호박은 같은 호박의 품종 01, 20개. 화면 이름 주키니와 코드표 표기 쥬키니를 둘 다 받는다. 호박만 넣으면 애호박과 쥬키니가 겹쳐 받지 않는다. 2024-10-28 주간과 2026-10-20 주간의 단위가 같다. 커밋 `03cc2dd`.

배포된 웹 앱이 본문에 실린 부류·품목·품종 코드로 시트를 썼다. 다섯 품목 모두 2024-10-28~2026-10-28 일별 487일이다. 2026-10-28 상품 평균은 조사 시장 평균과 같다. 양배추 10,852원(시장 5곳), 청오이 17,467원(3곳), 팽이버섯 9,604원(5곳), 주키니호박 12,440원(5곳), 애호박 21,860원(5곳).

## 휴대폰 화면

커밋 `e574d6a`. 좁은 화면에서는 제목 아래 긴 설명을 접고, 품목 칩은 가로로 넘긴다. 기간 버튼은 한 줄을 나눠 갖는다. 도매가 숫자는 더 크게 둔다. 차트 세로축 폭도 줄인다. 너비 524px 창에서 상추 최근 1개월, 칩과 기간 버튼, 2026-10-28 17,800원, 소량 분할 매입 카드가 한 화면에 이어졌다.

휴대폰에서 지금 여는 주소는 `https://relates-sol-characteristic-encoding.trycloudflare.com` 이다. 2026-10-29 21:17 (Asia/Seoul)에 이 실행 환경의 보기 전용 서버(127.0.0.1:3001)로 연결했다. 공개 주소의 상추 최근 1개월은 2026-10-28 17,800원, 매입액션은 소량 분할 매입이다. 화면 제목은 도매 시세와 매입 타이밍이고, 폭 390px 화면에서 품목 칩, 기간 버튼, 17,800원 카드가 보였다. 브라우저로 내려가는 HTML과 스크립트에는 시트 주소와 API 키가 없다. 이 서버는 시트 주소만 넣고 빌드했다. 품목 추가 버튼은 이 주소에서 구글 시트에 저장하지 않는다.

이 주소는 Cloudflare 임시 터널이다. 이 실행이 꺼지면 주소도 끊긴다. Vercel CLI 65.7.0은 로그아웃 상태이고, 로그인 없는 임시 배포는 거절됐다. 세션이 끝나도 열리는 주소는 `npx vercel login` 다음 `npx vercel --prod`로 만들고, 차트만 공개할 때는 환경변수 `SHEET_CSV_URL`만 넣는다. 품목 추가까지 휴대폰에서 하려면 `GAS_WEBAPP_URL`, `GAS_APP_TOKEN`도 서버에만 넣는다.
