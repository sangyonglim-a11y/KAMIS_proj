# KAMIS 도매 시세

대시보드 코드는 Wholesale price dashboard 작업 환경의 `~/kamis-dashboard`, 브랜치 `cursor/kamis-wholesale-dashboard-4f06`에 있다. 원격 저장소는 없다. 시트 연결 커밋은 `b526fa7`이고, 무 품종 전체 수집 커밋은 `ecf2b89`이다.

구글 시트 [KAMIS 도매 시세](https://docs.google.com/spreadsheets/d/1hKZvI3-q0tGP84-za1UTrswVRVdsTaR_Y1HkIiAuzZs/edit)는 링크 있는 모든 사용자 뷰어다. `품목`과 `시세` 탭이 있고, Apps Script 웹 앱은 2026-10-29 버전 1로 배포되었다. 실행은 계정 본인, 액세스는 모든 사용자, 시간대는 Asia/Seoul이다. 매일 7시(서울) `collectDaily` 트리거가 있다.

웹 앱 주소와 키는 `.env.local`과 스크립트 속성에만 있다. 상추는 2024-10-28부터 2026-10-28까지 일별 487일이 시트에 들어 있다. 2026-10-28 도매가는 17,800원이고, 매입 액션은 소량 분할 매입이다.

무는 품종 전체의 상품 20kg 시장 단순 평균이다. 시트에는 2024-10-28부터 2026-10-28까지 487일이 있다. 2026-10-28 가격은 13,011원이고, 매입 액션은 매입 보류다. 배포된 웹 앱 버전 1은 아직 가을 무라서, 화면의 품목 추가로 무를 다시 넣기 전에 웹 앱을 다시 배포해야 한다. 매일 7시 트리거는 Head라 다음 수집부터 품종 전체를 쓴다. 배추는 가을 품종만 연결한다.

추가 품목 커밋은 `03cc2dd`와 `51eddc0`이다. 양배추 200/212/00 8kg, 청오이(취청) 200/223/03 50개, 팽이버섯 300/316/00 5kg, 주키니호박 200/224/02 10kg, 애호박 200/224/01 20개, 새송이버섯 300/317/00 2kg. 여섯 품목 모두 2024-10-28부터 2026-10-28까지 487일이다. 새송이 2026-10-28은 8,432원이고 매입 액션은 소량 분할 매입이다. 품목 시트의 품종코드는 앞자리 0이 빠졌고, 매일 7시 수집이 두 자리로 맞춘다.

휴대폰 화면은 커밋 `e574d6a`에서 좁은 폭에 맞췄다. 긴 설명은 접고, 품목 칩은 가로로 스크롤되며, 기간 버튼은 한 줄을 삼등분한다. Vercel 계정은 로그아웃이라 배포가 거절되었다. `https://….vercel.app` 주소는 아직 없다. 휴대폰에서 당장 여는 주소는 Cloudflare 임시 터널 `https://relates-sol-characteristic-encoding.trycloudflare.com`이고, 이 실행이 꺼지면 끊긴다. 보기 전용이다. 상추 2026-10-28 도매가 17,800원과 소량 분할 매입을 그 주소에서 확인했다. 품목 추가는 이 주소에서 시트에 저장되지 않는다. 계속 쓰려면 `npx vercel login` 다음 `npx vercel --prod`로 공개 주소를 만든다. 차트만 공유할 때는 서버 환경변수 `SHEET_CSV_URL`만 넣고, `GAS_WEBAPP_URL`과 `GAS_APP_TOKEN`은 넣지 않는다.

최근 2년 차트의 말풍선은 커밋 `ebb6711`에서 고쳤다. 가로축 데이터는 전체 날짜이고, 눈금만 월·일이다. 말풍선은 연도.월.일을 보여 준다. 청양고추 2026-02-11은 137,800원으로 저장값과 같다.
